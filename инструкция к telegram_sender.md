# Telegram Sender — отправка текста из файла в Telegram

Python-скрипт, который читает текст из `.txt` файла и отправляет его в приватный Telegram-чат через бота.

## Что делает скрипт

1. Читает текст из указанного `.txt` файла
2. Отправляет его в Telegram-чат через бота
3. Автоматически разбивает длинные сообщения на части (лимит Telegram — 4096 символов)

## Настройка

### Шаг 1. Создайте Telegram-бота

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте ему `/newbot`
3. Выберите имя и username для бота
4. Скопируйте **токен** (формат: `123456:ABC-DEF...`)

### Шаг 2. Узнайте свой Chat ID

1. Найдите в Telegram бота **@userinfobot**
2. Отправьте ему `/start`
3. Он ответит вам ваш **ID** (число)

### Шаг 3. Создайте файл `.env`

В папке со скриптом создайте файл `.env` и впишите свои данные:

```
BOT_TOKEN=ваш_токен_от_BotFather
CHAT_ID=ваш_chat_id
```

### Шаг 4. Напишите боту

Откройте Telegram, найдите своего бота и отправьте ему любое сообщение (например, `/start`). Это нужно сделать один раз, чтобы бот мог отправлять вам сообщения.

## Запуск

```bash
python3 telegram_sender.py путь/к/файлу.txt
```

### Пример

```bash
python3 telegram_sender.py message.txt
```

```
Файл: message.txt
Длина текста: 116 символов
Отправка в Telegram...
Сообщение отправлено.
```

## Требования

- Python 3.10+
- Доступ в интернет (HTTPS)
- Дополнительные библиотеки **не требуются** — скрипт использует только стандартную библиотеку Python

## Возможные проблемы

### SSL-сертификаты на macOS

При установке Python с [python.org](https://python.org) на macOS он поставляется с **собственным хранилищем SSL-сертификатов**, отдельным от системного. Если Python выдаёт ошибку:

```
ssl.SSLCertVerificationError: [SSL: CERTIFICATE_VERIFY_FAILED]
```

Скрипт обрабатывает это автоматически, но для полноценной работы рекомендуется установить сертификаты:

```bash
/Applications/Python\ 3.13/Install\ Certificates.command
```

> Замените `3.13` на вашу версию Python (`python3 --version`)

Это безопасно — устанавливаются стандартные корневые сертификаты Mozilla, системные настройки не затрагиваются.
